# Stova

> Stova (formerly Aventri / eTouches) is an enterprise event management platform covering the full event lifecycle: registration, event websites, email marketing, surveys, abstracts, meetings, budgets, venue sourcing, on-site check-in, badging, lead retrieval, mobile apps, and reporting. It exposes a RESTful APIv2 with region-specific hosts (NA, EMEA, APAC) for data residency.

**Key Facts**

- **Modular Architecture** — Purpose-built modules (Registration, Websites, Email Marketing, Surveys, Abstracts, Meetings, Budgets, Projects, Venue Sourcing, Mobile Apps, On-site, Lead Retrieval, Reporting) that can be adopted independently.
- **Region-Specific API Hosts** — Dedicated hosts for NA, EMEA, and APAC support data residency compliance and lower latency.
- **APIv2** — RESTful API with JSON and XML support, organized by platform module.
- **Authentication** — Master and scoped API keys with IP-range restrictions, plus token-based auth.
- **Webhooks** — Registration and event-level triggers for create/modify/cancel/RSVP events without polling.
- **Data Services** — Bulk, paginated data endpoints for large datasets and reporting use cases.
- **Integrations** — Native integrations with Salesforce, Marketo, Concur, PayPal, and SSO (SAML/OIDC).

These facts make Stova suitable for enterprise and mid-market organizations running complex, multi-region event programs that need integrations with existing CRM, marketing, and travel systems.
